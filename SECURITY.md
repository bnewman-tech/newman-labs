# Security

Report suspected vulnerabilities through a private GitHub security advisory for
this repository. Do not open a public issue containing credentials, private
documents, personal data, or exploit details.

Newman Labs supports only the current production release. Security fixes move
forward through reviewed code and migrations; production databases are never
downgraded or reset as a remediation shortcut.

Include the affected URL or revision, reproduction conditions, observed impact,
and any relevant request or trace identifier. Remove secrets and document content
from the report unless they are required to demonstrate the issue.
